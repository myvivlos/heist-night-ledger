Night Ledger: a top-down stealth heist you play in the browser. Cross three museum vault
rooms, read the guard patrols and camera arcs before you move, crack the safe and walk out
through the exit door before the alarm meter fills.

## Run it

```sh
node serve.ts          # play at http://localhost:8080
MAKEFUN_OUTPUT_DIR=out node main.ts   # write out/ with the game, screenshots, dossier
```
